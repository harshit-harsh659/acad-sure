# APAAR Student Data Management & Verification System

AICTE Hackathon Prototype for national-level academic identity, enrolment monitoring, and institutional data verification.

## Module Structure

- **Module 1**: Authentication & Frontend Foundation (`frontend/`) — *Completed*
- **Module 2**: Institutional Student Record Management & CSV/Excel Ingestion — *Upcoming*
- **Module 3**: Intelligent Data Validation & Anomaly Detection — *Upcoming*
- **Module 4**: AICTE Monitoring & Enrolment Discrepancy Dashboard — *Upcoming*
- **Module 5**: Authorized Academic Credential Verification Pipeline — *Upcoming*

## Quick Start (Frontend Module 1)

```bash
cd frontend
npm install
npm run dev
```

Visit [http://localhost:5173/](http://localhost:5173/) to view the authentication interface.

For full architectural details, see [frontend/README.md](frontend/README.md).
